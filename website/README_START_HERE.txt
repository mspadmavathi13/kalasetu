KALASETU + BHASHINI LIVE
========================

This package connects the supplied KalaSetu HTML prototype to a local Node.js
backend. The backend keeps the BHASHINI key out of the HTML and calls the
BHASHINI Dhruva inference pipeline for ASR + translation.

1) REQUIREMENT
   Install Node.js 18 or newer.

2) CONFIGURE BHASHINI
   Open .env and set:

   BHASHINI_INFERENCE_API_KEY=YOUR_REAL_KEY
   BHASHINI_ASR_SERVICE_ID=YOUR_ASR_SERVICE_ID
   BHASHINI_TRANSLATION_SERVICE_ID=ai4bharat/indictrans-v2-all-gpu--t4
   PORT=8787

   Do NOT paste the key into index.html.

3) START
   Double-click start-kalasetu.bat
   OR in this folder run:

   npm install
   npm start

4) OPEN
   http://localhost:8787

5) VERIFY
   Open:
   http://localhost:8787/api/health

   You want:
   "bhashiniConfigured": true
   and an empty "missing" array.

6) TEST THE DEMO
   In KalaSetu -> Start Your Craft Journey -> Input & Capture:
   select Kannada, press the microphone, speak, then stop.

   Expected flow:
   Kannada voice -> BHASHINI ASR -> Kannada transcript ->
   BHASHINI/AI4Bharat translation -> English translation.

NOTES
-----
- The original HTML is preserved at public/KalaSetu_Microphone_Fixed_Original.html.
- This build changes the voice API integration so the WAV generated by the HTML
  is sent as WAV, not incorrectly labelled as WebM.
- /api/bhashini/voice now performs ASR and then translation in one request.
- If translation fails but ASR succeeds, the transcript is still returned.
- The BHASHINI API key is never sent to the browser.
- The package cannot contain your private key because it was not supplied here.
  Put it only in the local .env file.
